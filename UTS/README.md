## 🔬 Topik Penelitian

Penelitian ini membahas klasifikasi penyakit daun padi menggunakan metode **Convolutional Neural Network (CNN)** dengan augmentasi data. Dataset yang direncanakan berasal dari Kaggle, yaitu [Leaf Rice Disease Indonesia](https://www.kaggle.com/datasets/tedisetiady/leaf-rice-disease-indonesia).

Penelitian akan membandingkan performa model CNN tanpa augmentasi dan dengan augmentasi data menggunakan metrik accuracy, precision, recall, F1-score, dan confusion matrix.

---

## 🎯 Tujuan Penelitian

- Menerapkan CNN untuk klasifikasi penyakit daun padi.
- Mengetahui pengaruh augmentasi data terhadap performa klasifikasi.
- Mengevaluasi hasil model menggunakan metrik klasifikasi.
